# SayAnonymous frontend

The active app uses React and Vite. Follow the [repository setup](../README.md) and run `npm run dev` from the repository root to start the interface and API together.

The active screens are in `src/prototype/`. Earlier pages and components remain as reference material and are not mounted by `src/App.js`.

Run `npm run build` from the repository root to produce `frontend/dist/`.
